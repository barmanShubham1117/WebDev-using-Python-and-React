# HTML5 Declaration 
```html
<!DOCTYPE html>
```
    - The Document Type: HTML
    - Used to specify browser that the loaded file contain HTML version 5 code

# Paragraph Tag
```html
<p>
    Write your text here. It represents a paragraph of your content.
</p>
```

# Image Tag
```html
<img src="<path_of_your_image>" alt="<alternate_text>">
```
- 'src' and 'alt' are attributes of the image tag.
